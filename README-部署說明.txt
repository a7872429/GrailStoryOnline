傳說紀行｜PHP 7.3.4 網頁版部署說明

本版本不需要 Node.js、Cloudflare、D1、MySQL，也不需要在玩家電腦啟動任何服務。
伺服器需求：PHP 7.3.4 或以上、允許 PHP 寫入檔案。

部署方法
1. 將壓縮檔解壓縮。
2. 把解壓後「資料夾裡面的全部內容」上傳到網站根目錄（例如 public_html 或 wwwroot）。
3. 確認以下網址可以開啟：
   https://你的網域/index.php
4. 若建立房間時顯示「無法建立房間資料夾」或「房間資料無法寫入」，請在主機檔案管理器把 storage 與 storage/rooms 設為可寫入。一般設為 755；若主機仍無法寫入，再依主機商說明改為 775。
5. 開房者建立房間，把六位房號傳給另一位玩家；另一位玩家從同一網址加入。

重要事項
- 不要刪除 storage/.htaccess，它會避免玩家直接下載房間資料。
- 如果主機使用 Nginx 而不支援 .htaccess，請請主機商禁止外部存取 /storage/ 路徑。
- 房間 24 小時未使用會由系統自動清理。
- PHP 主機若啟用了網頁快取，請排除 api/rooms.php，否則雙方同步可能延遲。
- 網頁必須透過網站網址開啟，不要直接雙擊 index.php。

更新版本
保留 storage 資料夾，只覆蓋 index.php、api、game 等程式檔案即可。
